# Cartera VALUE ex-USA

Simulación de una cartera **value** de 10.000 € en Interactive Brokers (cuenta en EUR, plan Tiered), gestionada por
Claude con decisiones por **valor esperado (EV)**, sin empresas de EE. UU. y con un comité de dos agentes
independientes que cuestiona cada compra. Horizonte mínimo: 1 año en virtual.

- **Panel:** https://claude.ai/artifact/46h4ity964Kmw8rMaB8dxR
- **Registro de operaciones:** [`ledger/operaciones.csv`](ledger/operaciones.csv) (solo añadir)
- **Tesis:** [`tesis/`](tesis) · **Diario:** [`diario/`](diario) · **Informes:** [`informes/`](informes)

17:00 Nueva York (cierre, solo revisión). Domingos 18:00 Madrid: cribado y plan semanal.
